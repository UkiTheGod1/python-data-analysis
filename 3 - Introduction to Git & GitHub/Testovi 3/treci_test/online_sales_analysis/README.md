## Project

Project is about store product management and functionalities.

## Classes

There are 3 classes:

- Product: Defines product name, price and quantity. Contains 2 functions: Display Info and Update Quantity

- Product Manager: Contains product list and functions that place products in the product list, displays the products in the list, displays total value of the list and function that removes product from the list.

- Cart: Contains its own list where you can add products into from the product list, calculate the total value of the cart and display the products that are in the cart.
